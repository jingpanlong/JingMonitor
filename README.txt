本次调整
--------
改为独立桌面悬浮窗，不再提供覆盖任务栏或嵌入通知区的显示方式。
升级时自动把旧版任务栏设置迁移为悬浮卡片，默认出现在主屏右侧上方。
16 款内置皮肤全部重做：不同渐变背景、装饰纹理、边框及数据排版。
皮肤工坊与实际悬浮窗使用同一个矢量渲染器，背景不需要下载图片。

使用
----
请先从系统托盘退出旧版本，再运行 JingMonitor-1.3.0.exe，或使用新版安装程序。
无需预装 .NET。EXE 未代码签名。
按住悬浮窗拖动即可移动；双击打开控制台；右键可锁定位置或恢复窗口。
位置自动保存；松开鼠标后窗口会保持在工作区内，避开任务栏。
控制台“显示与提醒”可切换悬浮卡片/悬浮球，调透明度、置顶、点击穿透及位置锁定。
点击穿透后请从系统托盘菜单关闭，或选择“恢复监控窗到桌面”。
右上角 × 收起到托盘；完全退出请使用托盘菜单。

DIY
---
在皮肤工坊导出 JSON 模板，编辑后导入，可继续分享给他人。
Name 为唯一名称。Background / Background2 为渐变背景两端；
Border 为描边；Foreground / Accent / Upload 为信息配色。
Pattern 可选：aurora, stars, glacier, sunset, petals, paper, facets, mountains,
waves, honeycomb, grid, clouds, linen, orbits, sonar, bloom。
Layout 可选：split（双栏）, stack（纵向）, terminal（仪表）。
Radius 为圆角（0–50），FontSize 为字号（10–24）；ShowCpu / ShowMemory 控制系统指标。
颜色使用 #RRGGBB 或 #AARRGGBB；文件不超过 64 KB；不执行脚本。
旧 JSON 皮肤仍可导入，新增字段使用默认值。预览使用示例数据，悬浮窗使用实时数据。

监控功能
--------
每秒采集真实网速、CPU、物理内存；硬件温度和 GPU 数据通过 LibreHardwareMonitor。
硬件初始化与网络采集独立；没有硬件传感器数据时明确显示不可用，不伪造数值。
部分硬件温度需管理员权限及 PawnIO 驱动。程序不自动安装驱动或更改系统安全设置。
驱动及硬件支持说明：https://github.com/LibreHardwareMonitor/LibreHardwareMonitor
支持本地日流量历史、CSV 导出、内存/温度/日流量阈值提醒，同类提醒最多每 5 分钟一次。
流量仅记录运行期间，自动汇总虚拟网卡可能重复计数，建议选择实际物理网卡。
正常每约 15 秒及退出时落盘。通知受 Windows 通知设置影响。
没有在线皮肤市场，通过 JSON 手动分享与导入。

数据
----
%LOCALAPPDATA%\JingMonitor
settings.json / traffic.json / skins.json / diagnostic.log
不上传监控数据。卸载保留个人设置、流量与 DIY 皮肤。

源码构建与测试
--------------
需要 .NET 8 SDK x64。源码根目录运行 .\build.ps1，输出到 dist。
首次构建需访问 NuGet。安装器使用 Windows 的 .NET Framework 编译器。
JingMonitor.exe --self-test：网络、存储、皮肤及慢硬件初始化回归。
JingMonitor.exe --smoke-test：独立测试数据目录，截图六个页面、全部皮肤和悬浮窗后退出。
JingMonitor-Setup.exe --verify <目录>：仅提取安装器资源进行校验，不执行真实安装。

1.2.0 新增：透明度、四边隐藏和图片背景
----------------------------------
显示与提醒 → 窗口不透明度：10%–100%，实时调整整个悬浮窗。
勾选“靠近屏幕边缘后自动隐藏”，拖到上/下/左/右边缘松开即可缩为提手。
也可点击方向按钮或通过悬浮窗右键直接选择边缘。
鼠标进入提手立即展开，离开约 0.75 秒后缩回；锁定位置不妨碍展开。
隐藏位置以屏幕可用工作区为边界，在任务栏内侧保留提手，不覆盖通知区。
提手使用至少 65% 不透明度，避免透明度较低时无法找回。
“恢复监控窗到桌面”会关闭吸边隐藏和点击穿透，恢复正常卡片。

显示与提醒 → 自定义背景图片：选择 PNG / JPEG / BMP（不超过 20 MB）。
图片会转换并复制到 %LOCALAPPDATA%\JingMonitor\backgrounds，不上传网络。
导入后移动或删除原图不影响已导入的背景。
可单独调节图片不透明度、文字遮罩强度，并选择居中裁切铺满或完整显示。
自定义照片上使用浅色文字；遮罩用于增加可读性，设得过低可能影响数字对比度。
“恢复内置背景”恢复当前皮肤的矢量背景。
背景图片覆盖是本机显示设置；导出 DIY 皮肤 JSON 不包含照片文件。

--smoke-test 额外验证四边提手、鼠标指针状态转换、窗口透明度、图片导入后
删除原文件仍可显示、图片铺满/完整显示及恢复内置背景，并生成对应截图。
1.3.0 修复与界面更新
-------------------
靠边隐藏默认启用：从旧版升级时会自动启用一次。
拖到边缘松开后，鼠标仍在窗口内时保持展开；移开约 0.75 秒后缩回。
鼠标移到提手立即展开。窗口移动后与空闲期间都会检测四边，不再只依赖拖动结束事件。
可从悬浮窗右键菜单的“立即隐藏到边缘”直接指定方向。
恢复到桌面后仍保留自动靠边检测，避免恢复操作意外关闭这项功能。
如果不希望靠边隐藏，可在设置或右键菜单中取消勾选并保存。

标题栏右上角新增浅色/深色切换按钮，设置页和两个右键菜单也可切换。
主题覆盖控制台、设置、下拉框、输入框与菜单。悬浮窗背景仍由皮肤/图片独立决定。
新主题会保存，重启后恢复。

全新 J 流线加上行箭头品牌 Logo，应用于控制台、关于页、悬浮卡片/球、程序窗口、
EXE 文件、安装器、卸载程序、快捷方式和系统托盘。ICO 提供 16–256 像素多尺寸。
悬浮窗和托盘使用统一的圆角 WPF 菜单，具有图标、分组、子菜单和勾选状态。
输入框提供同风格的剪切/复制/粘贴/全选菜单；安装器路径输入框也有配套菜单。
新版安装器会提示 Explorer 刷新图标。

开发说明：Brand.cs 是 Logo 的绘制源；编译后可运行
JingMonitor.exe --export-brand <源码中的 JingMonitor 目录>
